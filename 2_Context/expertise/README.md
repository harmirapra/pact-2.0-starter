# Expertiza

> Doménová znalost, kterou agent nemá odkud vzít — terminologie tvého oboru, pravidla, která u vás platí, věci, které jsou ve tvé firmě samozřejmé a jinde ne.
>
> Rozdíl proti `identity/about-me.md`: tam je, **kdo jsi**. Tady je, **co víš**.

## Jak si to členit

Jeden soubor na jednu oblast, pojmenovaný podle ní — třeba `pojistovnictvi.md`, `interni-procesy.md`, `nastroje.md`. Tenhle `README.md` zůstává jako rozcestník.

Do souboru patří: pojmy a jejich význam · pravidla a omezení, která u vás platí · typické chyby, kterých se lidé v oboru dopouštějí · zdroje, kterým věříš.

Nepatří sem: to, co si model dohledá sám · aktuální projekty (ty jsou v `0_Projects/`) · kritéria kvality (ta jsou v `2_Context/quality-criteria.md`).

## Než sem něco napíšeš

Kontrolní otázka: *dostal by agent tuhle informaci sám?* Když ano, nepiš ji — jen zabírá kontext. Cenné je to, co ví jen tvoje firma nebo tvůj obor.

Znalost sem můžeš nechat vytáhnout ze zdrojů dovedností `knowledge-extractor`.
